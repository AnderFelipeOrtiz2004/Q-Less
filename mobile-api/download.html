Instalación en el celular
  1. Pulsa el botón verde y espera la descarga.
  2. Abre el archivo Q-LESS.apk desde Notificaciones o Descargas.
  3. Si Android lo pide, activa Instalar apps desconocidas para Chrome o Archivos.
  4. Abre Q-LESS y usa Iniciar sesión con Google o registro Gmail.
